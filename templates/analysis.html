PyMongo Pipeline Snippets

These actual MongoDB aggregation pipelines are executed in `app.py` to calculate the analysis figures above:

// 1. Top Movies by Average Rating ($group, $match, $sort, $limit)
pipeline = [
  {"$group": {
      "_id": "$movie_title",
      "avg_rating": {"$avg": "$rating"},
      "total_ratings": {"$sum": 1},
      "genre": {"$first": "$genre"}
  }},
  {"$match": {"total_ratings": {"$gte": 5}}},
  {"$sort": {"avg_rating": -1, "total_ratings": -1}},
  {"$limit": 10}
]
// 2. Genre Performance ($group, $avg, $sum, $addToSet)
pipeline = [
  {"$group": {
      "_id": "$genre",
      "avg_rating": {"$avg": "$rating"},
      "total_ratings": {"$sum": 1},
      "distinct_movies": {"$addToSet": "$movie_title"}
  }},
  {"$sort": {"avg_rating": -1}}
]
